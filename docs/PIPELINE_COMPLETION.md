# Week 3–Week 11 pipeline completion

This update extends the existing incremental pipeline. It does not download
or fabricate missing historical data. Prepared bond and historical clean
listing files remain valid inputs for an incremental update.

## Inputs and one command

Run from the project directory: `python .\update_airbnb_pipeline.py`.
Inputs are monthly summary downloads in `local_data/YYYY_MM.csv`, the previous
clean and geocoded listings, and cleaned rental bonds in `processed_data/datasets`.
The optional original `local_data/christchurch_2025_10_to_2026_06.csv` supplies
historical review fields. Full national June analysis needs `2026_06.csv`.
Scrape dates are the project's existing configured dates, not download dates.
Additional unconfigured months stop with an error rather than guessing dates.

## Steps and outputs

1. Discover raw months and apply the existing listing cleaner.
2. Replace those months; preserve other months; reject duplicate ID/month keys.
3. Match CSV coordinate precision before looking up SA2 cache entries.
4. Geocode unseen coordinates only. When all coordinates are cached, make no
   network requests and require no API key. New requests require a key and a
   successful known-point test before batch requests.
5. Re-run the existing validated bond left join and copy its report to docs.
6. Save monthly charts, Christchurch price histogram, available raw review-age
   histogram, latest Christchurch review ranking, and per-column statistics.
7. Produce price-gap and property-count charts for the newest month with bond
   matches. Preserve August's missing bond values in the latest-month report.
8. Write balanced row accounting, final checks, missing-source coverage and a
   local HTML gallery containing the charts generated by the run.

`processed_data/reports/pipeline_validation_report.md` and `processed_data/statistics/validation_report.json` document usable
rows separately for prices, reviews and bond comparisons. A review histogram
with July/August inputs covers July/August only. Raw category statistics report
each observed category and its count; numeric statistics include min/max/mean/std.
Price histogram limits affect display only. No price or bond value is imputed.

## Coding practices and checks

Small named functions separate raw-source collection, statistics, plots and
reporting. Existing cleaning and many-to-one join validation are reused.
The gallery uses relative local links. Source coverage is explicit; successful
execution is not a claim that missing historical inputs or course evidence
have been completed. Cached runs are tested without an API key.

document. Team members must review the code, outputs and interpretation.
